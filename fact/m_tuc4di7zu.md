# Instinct's GitHub connection is read-only and cannot run Actions

As of 2026-09-27, Instinct's GitHub connection could read repos but could not run GitHub Actions workflows, such as the Daily job sweep in jkong7/jobsearch. Connecting Instinct for Actions needs write access granted inside Instinct's settings or a fine-grained token that Jonny creates himself.
