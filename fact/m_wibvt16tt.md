# Brain capture pipeline

Captures enter through the phone Brain shortcut (Todoist Inbox), Mac ⌥J statements (~/brain/inbox/), Instinct, and forwarded email. An hourly cloud Capture Triage run files them, does requested work (research, prep, drafts, builds), and logs journal entries.
