# ⌘4 job-application run

⌘4 is Jonathan's single keypress for the job-application run. It opens a Claude session in ~/dev/jobsearch that fills pending Instinct handoff packets first, then the top 15 open pipeline roles by queue priority. Each run starts only when he presses the key.
