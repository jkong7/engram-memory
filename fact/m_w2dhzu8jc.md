# Gmail dashboard layout

Jonny's Gmail uses a Multiple Inboxes layout, set up 2026-09-21. Sections above the main inbox are Interviews & Offers (last 60 days), Replies (last 30 days) and Recent rejections (last 14 days). It replaces the Primary, Promotions and Social tabs.
