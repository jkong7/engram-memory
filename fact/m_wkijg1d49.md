# lean cleanup tool in flow-kit

flow-kit 0.6.0, pushed 2026-10-04, adds `lean`, a terminal command that lists heavy services, caches, worktrees, models and old folders without deleting anything. It also adds a /lean Claude Code skill that removes only the items Jonny selects.
