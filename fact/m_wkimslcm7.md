# Local LLM setup on Mac

Jonny's Mac has 48 GB of RAM and runs Ollama locally. Installed models as of 2026-10-04: llama3, qwen3:8b and nomic-embed-text. `ollama stop <model>` frees a loaded model's RAM immediately, while `/bye` only exits the chat.
