# How the personal Gmail is organized (Jobs/* labels, 18 imported filters, unsubscribes) and how to change it

Set up 2026-09-21 on jonathankong677@gmail.com ([[gmail-connector-account]]).

Labels: Jobs/1 Interview (starred), Jobs/2 Offer (starred), Jobs/3 Replies (humans, LinkedIn DMs/InMail, invite acceptances), Jobs/4 Applied (all ATS mail; pure confirmations skip inbox), Jobs/5 Rejected, Jobs/6 Alerts (skip inbox), School, Finance. Travel/Receipts labels deliberately NOT used: Gmail's built-in Purchases/Travel views cover them.

Filters: 18, imported via Settings > Filters > Import from XML generated by gmail_filters_gen.py (in this memory dir). Promotions/Social/LinkedIn feed/job boards/other-college admissions skip inbox. Inbox archived older_than:30d. ~57 marketing senders unsubscribed via #sub page; LeetCode, Snapchat, Quora need website unsubscribe.

**Why:** user is starting a job search (see [[jobsearch-pipeline]], ~40 applications/day) and wants company/recruiter responses prioritized, possibly under multiple labels.
**How to apply:** to change rules, edit the generator, delete old filters in Gmail, re-import. The Gmail connector cannot create filters; use Chrome. Human-reply detection by keywords is approximate; a routine that labels threads containing a SENT message + external reply would be more precise (offered, not built).
