# Abridge Query Engine project

Jonathan's proudest Abridge project from summer 2026 was Query Engine. It is a Temporal pipeline that runs after note generation, finds billing-relevant gaps in AI-drafted notes, and writes one-click clinician questions. It went to GKE rollout, reached 73% clinician acceptance, cut about 150 billing follow-ups a month, and is in production.
