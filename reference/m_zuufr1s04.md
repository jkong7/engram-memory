# Fragella API and terms

Fragella (api.fragella.com) is the fragrance catalog API Verdict plans to use, covering 80,000+ fragrances. Its terms are at api.fragella.com/terms-of-use.html (updated 2026-05-04). Section 3.3 bars caching large portions of API data unless the plan permits it, and search returns at most 10 results per request, two pages deep.
