# vigil local workbench dashboard

vigil runs locally on Jonathan's Mac at http://127.0.0.1:7777 and starts at login. It shows what to build today, live Claude Code sessions, prompts per day, repo status and backlog items. `make open` opens it and `make logs` shows the log.
