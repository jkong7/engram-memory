# lantern GitHub publisher

jkong7/lantern is the private GitHub repo for Lantern (~/dev/lantern), set up 2026-10-08. A launchd agent, com.jkong7.lantern-publish, pushes its queued commits one at a time with random 10 to 90 minute gaps. Its log is ~/Library/Logs/lantern-publish.log.
