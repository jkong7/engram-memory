# Brain learns about Jonny

Jonny asked whether his Todoist vent captures were being used to learn about him, and the assistant found they were only archived in the journal. He asked for the vault to build a profile from what he says, and the assistant wrote profile notes in ~/brain/me, updated the vault rules and the Capture Triage and Weekly Review routines, and shipped a plugin so Claude Code loads the profile at startup. Jonny then asked for all personal details to be included, and the assistant removed the exclusion, so personal details now go into the profile.
