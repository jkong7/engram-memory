# Ledger updates, InternDock sweep and application batches

Jonny asked the agent to update his ledger with the completed Replit interview and the Wells Fargo and Visa OAs, then to scan the Sep 29 job board for new roles. The agent pulled about 1,750 software and data internships through InternDock's API and built a shortlist artifact of roles at companies not already in the ledger. It then opened and pre-filled batches of applications in Chrome, which Jonny asked to be kept to a small number of tabs. Jonny submitted about twelve applications himself on 2026-09-30, and the agent marked them Applied and blocklisted those companies.
