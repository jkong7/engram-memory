# Gmail and Mac organization

On 2026-09-21 Jonny asked for Gmail organization. The agent created job labels (Jobs/1 to Jobs/6) with filters, archived mail older than 30 days, unsubscribed from dozens of senders, built a multiple-inboxes dashboard, and scheduled a twice-daily Ledger Sync. Jonny then gave standing permission to clear useless mail, and the agent trashed newsletters, digests and promos. On the Mac, the agent moved code into ~/dev, set up screenshot and document folders, emptied the Trash (8.9 GB freed), and backed up the resume repo to a private GitHub repo. RAM tuning was judged unnecessary on the 48 GB machine.
