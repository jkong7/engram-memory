# Burner moves to production baseline

Between 2026-10-08 and 2026-10-10 Jonny asked what Burner needs before consumer launch. The work moved player data to Supabase Postgres with email sign-in, moved media to a private GCS bucket, added daily spend caps, deployed the app to Cloud Run and worked through the prelaunch safety checklist. Jonny set up two-factor login and a support Gmail, scaled persona-onboarding to zero, and dropped the university IP check. The live site runs but is not yet shared; trademark clearance and lawyer review remain open.
