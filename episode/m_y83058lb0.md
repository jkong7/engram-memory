# Caffeinate toggle shortcut

Jonny asked for a ⌘-key shortcut that toggles caffeinate -d in the background without a terminal window. The assistant built ~/.local/bin/caffeinate-toggle with a PID file and bound it in skhd. It first bound ⌘O, which would override Open in every app, so it moved to ⌘⇧O. The first binding went into a stray ~/.skhdrc that skhd never loads, so the assistant moved it to ~/.config/skhd/skhdrc and restarted skhd. The hotkey press itself was not verified from the session. Jonny then asked how to write in his voice, and the assistant pointed to the rules in ~/brain.
