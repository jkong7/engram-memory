# Read and organized Apple Notes via AppleScript

Jonny asked the agent to read his Apple Notes. No Notes connector existed in the session, so the agent read all 66 notes through AppleScript in Terminal. Jonny confirmed the agent had write access and asked for the notes to be organized into folders. The agent moved them into Journal, Thoughts, Career and Personal folders. Two audio-only notes ended up in Recently Deleted and needed manual restoration by Jonny.
