# Voice spacebar auto-submit in Claude Code

Jonny asked how to make Claude Code's spacebar voice input send the prompt on release. The assistant found an `autoSubmit` setting in a search snippet and added `"autoSubmit": true` under the voice settings in `~/.claude/settings.json`. It has not been tested with a microphone and needs a Claude Code restart to load.
