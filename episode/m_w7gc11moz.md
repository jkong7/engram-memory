# Chartside buildout and push to private repo

Jonny asked the agent to keep improving the Chartside ambient scribe to match a real scribe startup, based on research into the top 10 scribes. Over the session the agent built many features (co-signature and addenda, Inbox, dictation, documents, quality measures, inpatient, ED, oncology, group therapy, PT/OT, prenatal, HL7, check-ins, accessibility fixes, multi-site locations) and committed them locally, reaching 152 unpushed commits. When Jonny asked for the state of the repo, the agent confirmed nothing was pushed or deployed. Jonny then asked for all 152 commits to be pushed to the private jkong7/chartside repo at random 20 to 50 minute intervals, and a background push script was started.
