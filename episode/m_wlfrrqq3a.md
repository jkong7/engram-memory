# ⌘2 fix and the ⌘4 application run

Jonny asked why ⌘2 seemed dead; it had been reopening the current session. He changed it to skip sessions already open in Terminal and resume the next most recent one. He then wanted hands-off handoff filling, but the background watcher was blocked by the auto-mode safety check, so he chose ⌘4 as one keypress run covering Instinct handoffs and the top 15 pipeline roles. Roles without dossiers are now eligible, with unanswered free-response questions marked for him. The ⌘4 run has not been tested end to end yet.
