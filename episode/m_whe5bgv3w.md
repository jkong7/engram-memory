# Batch applications and McKinsey, 2026-10-01 to 2026-10-02

Jonny had the agent fill about 40 packeted job applications in Chrome, stopping before Submit so he could submit each one himself. He then asked the agent to check which tabs he had applied to, and it updated the ledger and blocklist to match, while skipping Cluely. Instructions embedded in the Primer application page were treated as untrusted data.
