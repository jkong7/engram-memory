# Filling Workday application forms in Chrome

Workday fills are unreliable, so verify each step. Typed ZIP and county fields may not save, so re-enter and recheck them. Dropdown picks can land on the wrong question, so set each one and confirm its value. Searchable lists need Enter to filter, and closing them with Escape can pick the wrong option, so click elsewhere instead. Pick the highest finished degree, since in-progress options may be unavailable. Resume uploads can be parsed but misplaced under Additional Files, so use the Resume slot's Select menu. Use the Review page to catch unsaved fields, then go back through Next to fix them.
