# Reconnecting Claude in Chrome for browser application runs

If Claude in Chrome shows no browser for the session, fully quit Chrome (Cmd+Q) and reopen it. Check that the Claude extension is signed in with the same account as Claude Code and is not paused. If it still does not connect, toggle the extension off and on at chrome://extensions. After a Chrome restart, tab IDs change, so re-list the tabs before navigating any tab that holds a filled form.
