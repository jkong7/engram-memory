# Approving engram hooks in Codex

Codex won't run engram's six hooks until each is approved once. Log in with `codex login` (opens ChatGPT sign-in in the browser), run `codex` in any folder, type `/hooks`, approve SessionStart, UserPromptSubmit, Stop, PreCompact, PostCompact and SessionEnd, then exit.
