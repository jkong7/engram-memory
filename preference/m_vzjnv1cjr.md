# Terminal closes without prompt

Jonny wants Terminal windows to close automatically when Claude exits and to skip the ⌘W confirmation, so launcher sessions leave no leftover shell windows. This is set in the Clear Dark profile's Shell tab: close the window when the shell exits, and never ask before closing.
