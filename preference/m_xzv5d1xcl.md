# Verify applications by receipt email

Jonny sometimes submits application forms himself from the open tabs. When he asks what was submitted, the agent checks each one against Gmail receipt emails and the confirmation page. When he confirms a submission without a receipt yet, the agent records it as applied and flags the receipt as pending.
