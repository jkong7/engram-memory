# Open Greenhouse applications at the default job-boards.greenhouse.io/<slug>/jobs/<id> URL, never the embed/job_app link

Open Greenhouse applications at `https://job-boards.greenhouse.io/<slug>/jobs/<id>`, never at `https://job-boards.greenhouse.io/embed/job_app?for=<slug>&token=<id>`.

**Why:** Jonathan explicitly asked to stop using the embed link (2026-09-24). He reviews and submits from these tabs himself.

**How to apply:** Any time a Greenhouse tab is opened for filling, use the default job URL. The form is on the same page below the description. Related: [[browser-one-tab-per-application]].
